Note

Shortcuts are disabled while typing in text fields. Context-aware shortcuts only work in Library and Playlist views. Plain letter keys (A-Z) jump to the first artist starting with that letter in the library. Press the same letter again to cycle through matches.

Ignore words when sorting

Enter comma-separated prefixes to ignore. Case-insensitive.

Example
-> "The Beatles" sorts under B
-> "Los Lobos" sorts under L
-> "Le Tigre" sorts under T

The full name is still displayed - only the sort order changes.
